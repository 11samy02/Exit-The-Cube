# Everything the game says, in one place.
#
# A name in square brackets opens a pool. Every line under it is one thing
# the game might say there. Blank lines and lines starting with # are
# ignored, and nothing is quoted or escaped — a line is exactly the text
# between the margin and the end of it.
#
# Delete a pool and the game falls back on the lines built into it. Empty a
# pool and it does the same, so the way to silence something is to give it
# one blank-looking line rather than none.
